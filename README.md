# Leo Yao — Personal Portfolio

Live site: https://ylieo816.github.io/

A static personal website covering expertise, engineering experience, projects, research, patents, and contact information. GitHub Pages publishes the root directory of `main`.

## Editing

- `index.html`: displayed text, sections, and links.
- `style.css`: responsive layout and appearance.
- `script.js`: research abstract expansion.
- `assets/`: images and diagrams used by the site.
- `content.json`: structured reference content; the HTML is maintained directly and is not generated from this file.

Open `index.html` in a browser to preview locally. No build step is required.

Original research figures link to the associated publications. Conceptual diagrams and earlier-version figures are labeled in the page.
